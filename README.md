## 📚 Workshop Projects

### Day 1 – Sweet Crumbs Bakery Customer Support Assistant

**Project Overview**

Built an AI-powered customer support assistant for Sweet Crumbs Home Bakery using Groq and LangChain.

**Features**
- Integrated Groq LLM using LangChain.
- Created a custom system prompt to define assistant behavior.
- Implemented a bakery customer-support assistant.
- Integrated Meta Llama Prompt Guard to detect suspicious inputs.
- Built a `safe_ask()` function to filter potentially malicious prompts.
- Tested normal customer queries and prompt injection attempts.

**Technologies Used**
- Python
- Google Colab
- LangChain
- Groq API
- LLMs
- Meta Llama Prompt Guard

**Notebook:** `Day1_Sweet_Crumbs_Bakery_Assistant_Aravind.ipynb`
